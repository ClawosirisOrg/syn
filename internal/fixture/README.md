# Local fixture boundary

This package runs only synthetic/local fixtures using review.Fake. It has no GitHub, provider, or publisher client. Acquired bytes and trigger metadata supplied by a caller are **not authenticated**; no default-branch guidance, resolved owner, publisher App identity, or webhook signature is verified here. Caller delivery IDs are not authenticated; only a domain-separated SHA-256 fixture ID is retained, never the caller string. Custom safety detectors remain caller-controlled and must be isolated from network access.

Optional local prior evidence: set Input.Prior to &PriorHistory{CompletedCycles: count, LatestRecordIDs: ids}. The IDs must be the latest min(count, 8) canonical records for the same target, newest first; count=0 requires no IDs. Nil leaves the zero-history default, even if the store contains records. Run uses history.Project to reject mismatched IDs/counts/targets and to build metadata-only prior_record entries (evidence, never policy), including bounded prior findings with opaque source references. More than eight completed cycles requires exactly eight IDs and marks prior truncation as cycles, context truncation as history, and the omitted cycle count. Context bundle and fixture record identities change when explicit prior context changes. The authoritative cycle index, ordering, and freshness must be established by the caller; this local package does not discover or prove them. Do not pass raw prior source IDs or bodies as history.

A reviewed fixture record sets publication_intent=advisory_comment **only because** render.CreatePreview requires that contract value for a local dry-run body. This is not authority to publish. Fixture records carry fixture-only-policy-v1: and fixture-only-profile-v1: version prefixes, runner.name=fixture-only, runner.provider=none, and synthetic ownership.review_owner_id=fixture-only / publisher_app_id=1. No publication operation exists in this package.

**Mandatory downstream live-publisher gate:** reject every fixture-only version/runner/owner marker; never infer publish eligibility from PublicationIntent, a preview, or a persisted record alone. Independently require a current effective config.Resolve live publication grant with least-privilege credentials, authenticated trigger and pinned/complete authoritative acquisition, independently verified maintainer ownership and publisher App identity, approved isolated real runner, freshness/idempotency/reference validation, and a separate controlled publication path. None of those live attestations is provided by this fixture package. Until they exist and are enforced, publication remains disabled.
