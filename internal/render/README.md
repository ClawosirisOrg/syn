# Provisional Phase 1 advisory preview

`CreatePreview(store, recordID)` obtains the canonical record through `recordstore.Store.Get`, checks its validated reviewed/pass/advisory state, and returns a deterministic, at-most-2048-byte Markdown **create dry-run preview** plus one SHA-256 marker over the lowercased repository and shared issue/PR item number. It emits only fixed wording, validated schema/snapshot metadata and counts of the `review_issue` and `redaction` enum classes. No raw findings, identifiers, locators, runner metadata or repository name are interpolated. The marker is an identity locator, not proof of comment ownership.

This package does not accept an existing comment or compute an update diff; that requires publisher-owned comment retrieval and verification of the configured App author and unique matching marker. It cannot verify that finding source IDs belong to the admitted manifest, that manifest/context hashes match independently stored inputs, or that a snapshot is fresh: `Store` only holds the canonical record. This preview does **not** authorize publication. A future publisher must independently enforce provenance, freshness, policy, identity, uniqueness and uncertain-write reconciliation before any create/update. No API/network operations occur here.
